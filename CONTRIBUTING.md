# Contributing

Expense ledger is a personal project, so changes are made to suit its owner's use, but issues and ideas are welcome.

1. Open an issue first for anything larger than a small fix.
2. Create a branch from `main`.
3. Run `npm test` and make sure it passes.
4. Update `CHANGELOG.md` and open a pull request.

Please keep the app free of external services, and never commit real entries, bank details, backups or save files. The `.gitignore` blocks the usual file names, but check your diff before you push.
